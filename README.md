# Krushna Bhadane — Portfolio 🚀

A sleek, minimalist, and editorial developer portfolio built with semantic **HTML5**, **Vanilla CSS**, and lightweight **JavaScript** featuring a 3D aesthetic workspace, custom typography, glassmorphism, and responsive design.

---

## ✨ Features

- **Minimalist Studio Aesthetic**: Curated warm stone & sage color palette with organic topographic contour vectors.
- **3D Visual Composition**: Layered 3D objects, floating frosted glass plates, and an interactive dark code editor window.
- **Interactive Micro-Interactions**: Smooth 3D mouse parallax tilt, animated status indicators, and responsive button states.
- **Zero Framework Bloat**: Built purely with vanilla web technologies for lightning-fast performance and instant load times.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Markup & Structure**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Custom Design Tokens, CSS 3D Transforms, Backdrop Filters)
- **Scripting**: Vanilla JavaScript (ES6+)
- **Typography**: Google Fonts (`Oswald`, `Plus Jakarta Sans`, `JetBrains Mono`)

---

## 🚀 Getting Started

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/KrishnaBhadane/portfolio.git
   cd portfolio
   ```

2. Open with any local HTTP server:
   ```bash
   # Using Python 3
   python3 -m http.server 3000
   ```

3. Open your browser and visit: `http://localhost:3000`
